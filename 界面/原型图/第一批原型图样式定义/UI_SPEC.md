# 宋式仙册 · UI 规格标注稿（UI SPEC v1.0）

> **用途**：游戏引擎（Cocos / Unity / 微信小游戏等）与前端开发重建 UI 的统一依据。
> **配套文件**：`design-tokens.css`（色值/字号/组件样式，可直接引用）；`pages/`（24 个页面 HTML 结构参考）。
> **设计目标**：宋代修士使用的记录册。克制、留白、统一。不是现代仙侠手游，不是抽卡游戏。

---

## 0. 全局禁止项（红线）

| 禁止 | 说明 |
|------|------|
| 任何渐变（linear/radial gradient） | 包括按钮、卡片、进度条、背景 |
| 发光 / glow / 外发光描边 | 包括金色光晕、文字发光 |
| 强投影（box-shadow） | 组件层级用 1px 细边框区分，不用阴影 |
| 大面积金色 / 蓝紫铺色 | 品质色只允许出现在：1px 边框、小印章、小标签 |
| 玻璃拟态 / 毛玻璃 | 不使用 |
| 高饱和色 | 只允许使用本文件列出的色值 |

## 1. 色彩系统

### 1.1 核心色（仅 5 种，承担全部 UI）

| 名称 | HEX | 用途 |
|------|-----|------|
| 宣纸白 | `#E8E1D2` | **全局背景、卡片底、按钮底**（面积最大） |
| 墨黑 | `#1C1B18` | 全部正文文字、标题文字 |
| 青瓷青 | `#789B95` | 玉牌边框、标签描边、修为进度条、辅助点缀 |
| 宋灰 | `#8A867D` | 次要文字、占位图形、滚动条 |
| 古铜暗金 | `#A27B45` | 价格/点数数字、经验进度条、重要边框（如弹窗、结算卡） |

### 1.2 辅助色（仅层次区分，不大面积铺色）

| 名称 | HEX | 用途 |
|------|-----|------|
| 纸深 | `#D4CBB8` | 表头底、顶栏底、头像底、图片占位底、进度条轨道 |
| 纸更深 | `#C2B89E` | 全部 1px 细边框、分隔线 |
| 青瓷深 | `#5A7B75` | 标签文字、选中态指示 |
| 灰深 | `#6B6860` | 说明文字、表单标签 |
| 古铜深 | `#8A6537` | 主按钮边框、icon 徽章边框 |

### 1.3 数值色（仅状态数值，禁止他用）

| 名称 | HEX | 用途 |
|------|-----|------|
| 提升 | `#6FAF9B`（青绿） | 属性+、获得、成功、寿元进度条 |
| 中性 | `#8A867D`（灰） | 普通数值 |
| 降低 | `#B1443D`（朱砂红） | 属性−、失去、失败、消耗提示、**朱砂印章** |

### 1.4 品质色（仅 1px 边框 + 小印章 + 小标签）

| 品质 | HEX | 应用位置 |
|------|-----|---------|
| 凡 | `#B5B0A5` | 卡片边框、印章描边、标签描边+文字 |
| 稀有 | `#6B8FBE` | 同上 |
| 史诗 | `#9B6BBE` | 同上 |
| 传说 | `#A27B45`（=古铜暗金） | 同上；**传说不用亮金色，与古铜同色** |

**品质规则（重要）**：品质不改变卡片背景色。所有卡片一律宣纸白底。品质 = 边框色 + 右上角小印章 + 标题旁品质标签。

## 2. 字体系统

## 3. 间距 / 圆角 / 边框

- **间距基准**：4px。常用档位：8 / 12 / 14 / 16 / 20 / 28 / 36px
- **页面内边距**：上下 28px，左右 36px
- **圆角**：小 3px（按钮/标签/小件）、中 5px（卡片/玉牌）、大 8px（弹窗/结算卡）
- **边框**：统一 1px 实线 `#C2B89E`；强调边框 1px `#8A6537`（古铜深）
- **网格间距**：2 列/3 列 = 16px，4 列 = 14px，6 列 = 12px

## 4. 组件规格

### 4.1 按钮

| 类型 | 底 | 边框 | 文字 | 尺寸 |
|------|-----|------|------|------|
| 主按钮 | 宣纸白 | 1px 古铜深 | 墨黑 16px 小薇，字距 2px | padding 10×28px |
| 次级按钮 | 透明 | 1px 纸更深 | 墨黑 16px | 同上 |
| 文字按钮 | 无 | 无 | 灰深 13px | padding 6×12px |
| 小按钮 | 同主按钮 | 同主按钮 | 13px | padding 5×14px |
| **朱砂印章按钮**（重生等关键操作） | 朱砂红 `#B1443D` | 1px 同色 | 宣纸白 16px | padding 10×28px |
| 禁用态 | — | — | 透明度 0.4–0.7 | — |

交互：hover = 底变纸深 `#D4CBB8`。无放大、无发光。

### 4.2 信息玉牌

| 项 | 规格 |
|----|------|
| 底 | 宣纸白；边框 1px 青瓷青 `#789B95`；圆角 5px |
| 大牌 | padding 16px；圆形头像 64×64px（纸深底 + 1px 古铜深边框，内书法字 28px）；姓名 22px 书法；信息行 12px 灰深 |
| 小牌 | padding 8×14px 横排；标签 11px 灰深 + 数值 20px 书法墨黑 |

### 4.3 卡片

- 底：宣纸白；边框：1px（默认纸更深，品质卡用品质色）；圆角 5px；padding 16px
- 卡内图占位：高 120px，纸深底，圆角 3px，中央书法字 32px 灰色
- 品质印章：右上角 24×24px，1px 品质色边框，品质色书法字 10px，旋转 −8°，透明度 0.7
- 品质标签：padding 2×10px，11px，1px 品质色描边，透明底

### 4.4 进度条

- 轨道：高 8px，纸深底，1px 纸更深边框，圆角 4px
- 填充：纯色 — 修为=青瓷青，经验=古铜，寿元=青绿 `#6FAF9B`
- 标签行：11px 灰深，左右分布（名称 / 数值）

### 4.5 剧情文本区

- 面板：宣纸白底，1px 边框，圆角 5px，padding 24px
- 剧情标题 24px 书法；正文 15px 行高 2 首行缩进 2 字符，灰深色
- 插图位：高 180px，纸深底占位
- 选项按钮：整行，padding 14×18px，1px 边框，hover 底变纸深；消耗提示朱砂红 12px；一次性标记 11px 灰色居右

### 4.6 顶栏（游戏内）

- 底：纸深；1px 边框；圆角 5px；padding 10×18px
- 书册名 18px 书法；右侧小玉牌（寿/石）+ 32×32px 图标位

### 4.7 弹窗

- 遮罩：墨黑 40% 透明
- 弹窗：宣纸白底，1px 古铜深边框，圆角 8px，padding 28px，最大宽 420px
- 标题 22px 书法

### 4.8 结算评级卡

- 宣纸白底，1px 古铜深边框，圆角 8px，padding 30px，居中
- 评级名 36px 书法字距 6px；副行 14px 灰深

### 4.9 图鉴格

- 4 列网格，单格 4:3 比例，1px 边框，圆角 3px
- 已解锁：纸深底；未解锁：宣纸底 + 虚线边框 + 灰色"?"

### 4.10 物品行（商店/背包）

- padding 12px，1px 边框，圆角 3px
- 左图标 52×52px（纸深底 + 1px 边框，书法字 24px）；名称 15px 小薇；说明 12px 灰深；价格 18px 书法古铜深

### 4.11 后台表格

- 表头：纸深底，墨黑 13px 小薇，padding 10×14px
- 行：padding 9×14px，13px，行间 1px 纸更深；hover 行底变纸深

### 4.12 表单

- 标签宽 120px 右对齐 13px 灰深；输入框 padding 7×12px，1px 边框，圆角 3px，聚焦边框变青瓷青
- 行距 14px

### 4.13 分隔线

- 左右 1px 纸更深横线 + 中央 14px 小薇灰深文字（如"—— 选择 ——"）

### 4.14 印章（装饰）

- 36×36px（首页 56×56px），1px 朱砂红边框，朱砂红书法字，旋转 −8°，透明度 0.7

## 7. 引擎适配注意

1. **响应式**：本稿按桌面宽度设计（内容区约 1000px+）。小游戏为手机竖屏时，建议设计宽度 750px，所有尺寸按 0.5–0.75 等比缩放；网格列数相应减少（天赋卡 3 列→2 列，图鉴 4 列→3 列）。
2. **字体降级**：Google Fonts 不可用时自动降级楷体/宋体，布局不受影响。
3. **交互态**：仅定义 hover（底变纸深）与禁用（透明度）。点击反馈建议用 0.95 缩放或边框加深，不用光效。
4. **数值色彩语义**：提升=青绿、降低=朱砂红，全局一致，禁止互换或扩展。
