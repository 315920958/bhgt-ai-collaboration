# 部署与初始化指南

> 本文档记录 BHGT 服务端部署与初始化阶段需要手动执行的操作命令，供开发、运维与协助人员参考。后续新增种子数据、数据库迁移等初始化命令，统一记录在此。

## 一、初始化管理员账号

服务端首次部署后，需要手动创建第一个管理员账号，用于登录后台管理端 `bhgt-admin`。

### 1. 前置条件

执行命令前，请确认以下事项：

1. 终端已切换到 `bhgt-server` 目录；
2. 依赖已安装（首次需执行，见下方「依赖安装」）；
3. MongoDB 已启动（本机默认端口 **47017**，连接地址以 `.env` 的 `MONGODB_URI` 为准）；若线上库在服务器上，需先建本地隧道——Mac/Linux 跑 `scripts/tunnel-mongo.sh`，Windows 双击 `scripts/tunnel-mongo-win.bat`（保持窗口打开，用完关闭即断开）；
4. 环境变量文件已就绪：开发环境用 `.env.development`，生产环境用 `.env.production`（仓库已提供 `.env.example` 模板，复制改名即可）。

> **依赖安装（国内镜像，避免官方源超时）**
> ```bash
> npm install --registry=https://registry.npmmirror.com --no-audit --no-fund --ignore-scripts
> ```

### 2. 执行命令

**开发环境（默认）初始化管理员：**

```bash
npx ts-node scripts/seed-admin.ts \
  --username=13521011078 \
  --nickname=李睿凡 \
  --loginCode=17950121 \
  --isAdmin=true
```

**生产环境初始化**（连生产库 `bhgt`，需先准备好 `.env.production`）：

```bash
NODE_ENV=production npx ts-node scripts/seed-admin.ts \
  --username=13521011078 \
  --nickname=李睿凡 \
  --loginCode=17950121 \
  --isAdmin=true
```

### 3. 参数说明

| 参数 | 必填 | 含义 | 默认值 / 说明 |
| --- | --- | --- | --- |
| `--username` | ✅ | 登录用户名 | 即后台管理端登录账号，此处填手机号 |
| `--nickname` | ✅ | 昵称 | 管理员显示名称 |
| `--loginCode` | 否 | 初始登录口令 | **同时也是首次登录的密码**（未传 `--password` 时，服务端用 loginCode 做 bcrypt 哈希作为初始密码） |
| `--password` | 否 | 自定义初始密码 | 不传则等同 loginCode |
| `--isAdmin` | 否 | 是否管理员 | 默认 `true`；传 `false` 则创建普通账号 |

### 4. 行为说明

- **幂等**：脚本按 `username` 查重，账号已存在时不会覆盖原数据，只返回已有记录；可重复执行。
- **连库规则**：默认读 `.env.development`；命令前加 `NODE_ENV=production` 则读 `.env.production`（决定连接 `bhgt_test` 还是 `bhgt`）。
- **端口**：MongoDB 默认连接 `mongodb://localhost:47017`，实际以 `.env` 中 `MONGODB_URI` 为准。

### 5. 注意事项

- **首次登录**：用 `username`（13521011078）+ `loginCode`（17950121）登录后台管理端；建议登录后尽快在后台修改密码。
- 该命令主要用于**开发 / 测试环境**初始化；生产环境管理员创建方式与此一致（指定 `NODE_ENV=production`）。
- 若 MongoDB 未启动或 `.env` 缺失，脚本会报错退出，请先排查前置条件。
