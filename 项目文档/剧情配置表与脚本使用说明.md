# 剧情配置表与脚本使用说明

## 一、如何配置 Excel

文件：`剧情配置/事件与节点配置表.xlsx`

- 在「事件」Sheet 填事件名称、事件编号和大阶段名称。
- 在「剧情节点」Sheet 填节点名称、所属事件、节点子编号、剧情标题和正文。
- 节点完整编号由脚本自动生成：`事件编号_节点子编号`。
- 在「按钮」Sheet 填关联节点名称、序号、文案、类型和目标节点名称。
- 图片只填文件名或中文相对路径，例如：`平儿.jpg`、`/cg/清纯/平儿.jpg`。
- 「是/否」按实际填写；大阶段、事件、节点引用填写名称，不填写 ObjectId。

图片文件统一放在：`图片/`。

## 二、如何运行脚本

```bash
cd bhgt-ai-collaboration/scripts
npm install
```

先检查 Excel：

```bash
node sync-story-config.mjs --check
```

检查通过后同步数据库：

```bash
node sync-story-config.mjs --sync-db
```

同步脚本会自动上传图片、补全 Excel 图片路径，并在校验通过后写入 `bhgt_test` 数据库。数据库通过本地 `47017` 端口连接。

从数据库导出 Excel：

```bash
node export-story-config.mjs
```

导出文件默认保存到 `剧情配置/数据库导出_事件与节点.xlsx`。
