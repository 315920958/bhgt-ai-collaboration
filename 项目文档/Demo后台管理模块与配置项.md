# Demo后台管理模块与配置项

## 一、属性配置

基础属性和特殊属性使用同一张配置表。

| 配置项  | 说明        |
| ---- | --------- |
| 属性ID | 唯一标识      |
| 属性类型 | 基础属性／特殊属性 |
| 属性名称 | 玩家看到的名称   |
| 属性说明 | 属性介绍文案    |
| 最小值  | 允许的最小值    |
| 最大值  | 允许的最大值    |

当前特殊属性共3项：

- 气运；
- 投掷次数；
- 第三个特殊属性待定。

悟性的用途待定。

## 十二、相关规则说明

本节不是后台配置项，只用于说明各配置如何运行。

### 12.1 属性规则

- 基础属性用于战斗门槛判定；
- 战斗节点自行选择需要判定的基础属性；
- 气运决定随机补差区间；
- 投掷次数默认1次；
- 任意一次投掷通过，整场战斗成功；
- 第三个特殊属性和悟性用途待定。

### 12.2 节点与按钮规则

- 节点必须属于一个大阶段；
- 按钮必须属于一个节点；
- 每个按钮不能被多个节点共用；
- 节点决定实际展示几个按钮，默认3个；
- 系统先过滤不满足开启条件的按钮，再保留必现按钮，并随机补足显示数量；
- 最终随机结果由服务端保存，退出重进不能刷新；
- 不满足开启条件的按钮不显示；
- 小游戏是按钮的一种。

### 12.3 战斗规则

```text
基础属性全部达到门槛
→ 直接成功

存在不足属性
→ 根据气运生成随机补差值
→ 在不足属性之间平均分配
→ 向下取整，余数舍弃

本次投掷补足全部属性
→ 战斗成功

本次投掷失败且还有投掷次数
→ 再次投掷

全部投掷失败
→ 战斗失败
```

玩家只看到最终成功或失败，不显示门槛、随机值和补差值。

战斗成功后计算评分：

```text
分别计算各项判定属性超过门槛的数值
→ 将超额属性点相加
→ 按超额属性点总和匹配评分档位
→ 档位分值 × 全局评分乘数
→ 得到本次战斗评分
```

使用气运补差通过战斗时，以补差后的最终判定数值计算超额属性点。

### 12.4 小游戏规则

- 小游戏配置在节点中，由小游戏按钮启动；
- 一次性小游戏无论成功或失败，执行后都不能再次进入；
- 小游戏失败惩罚由结果档位配置；
- 临时属性变化只保存属性、变化数值和持续节点数；
- 临时属性变化在重生后清空。

### 12.5 物品规则

- 遗物获得后自动生效，不需要装备；
- 遗物只提供固定数值，不使用百分比；
- 遗物不能重复获得，也不能出售；
- 消耗品只能购买，不能由节点奖励；
- 消耗品使用后消失，重生后清空；
- 遗物和剧情道具可以购买，也可以由节点奖励；
- 剧情道具在按钮出现时不消耗，玩家点击对应按钮时才消耗；
- 未使用的剧情道具在重生后清空。

### 12.6 商店规则

- 商店通过节点配置开启；
- 商店开启后，全部已上架商品可见；
- 灵石不足时不能购买；
- 已经拥有的唯一遗物不能重复购买。

### 12.7 CG规则

- CG通过按钮、战斗或小游戏结果解锁；
- CG永久保留；
- 同一CG不能重复入库；
- 再次遇到时可以重新展示；
- 重复展示不转换成其他奖励；
- 玩家可以从图鉴回看。

### 12.8 重生规则

重生时清空：

- 当前等级；
- 当前寿元并恢复开局值；
- 灵石；
- 消耗品；
- 剧情道具；
- 非永久遗物；
- 临时属性变化；
- 当前节点进度；
- 本世按钮随机结果；
- 一次性按钮使用记录。

重生时保留：

- CG；
- 已经永久保留的遗物；
- 局外成长；
- 已解锁天赋。

每一世结束时，玩家可以从本世新获得的遗物中选择一件永久保留；以前各世保留的遗物不会丢失。

玩家重生后直接返回人生起始节点，不能跳过前期阶段。

### 12.9 评分与天赋规则

- 评分点数和天赋点是两种不同的数据；
- 战斗和小游戏结果可以增加或减少本次游戏的评分点数；
- 通关时根据最终评分点数进入对应评分档位；
- 评分档位奖励天赋点，评分点数本身不能用于选择天赋；
- 玩家消耗天赋点选择天赋，不直接把天赋点转换成属性点；
- 不同品质的天赋可以配置不同的天赋点消耗；
- 可同时选择的天赋数量随累计通关次数提高，具体上限由配置决定。
